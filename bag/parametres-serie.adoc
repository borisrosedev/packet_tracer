Les paramètres série sont des configurations essentielles pour établir une communication correcte entre deux dispositifs via un port série. Ces paramètres doivent être identiques des deux côtés de la connexion pour garantir que les données soient transmises et reçues de manière compréhensible.

Voici un aperçu des principaux paramètres série :

1. Baud Rate (Débit en bauds)
Le baud rate est la vitesse de transmission des données, mesurée en bauds (symboles par seconde). En général, le baud rate correspond au nombre de bits transmis par seconde (bps), mais il peut également inclure des bits supplémentaires comme les bits de parité ou de stop. Quelques baud rates courants sont :

9600 bps : Standard pour de nombreux périphériques série.
115200 bps : Utilisé dans des communications rapides.
4800 bps, 19200 bps, 38400 bps, 57600 bps : Autres options fréquemment utilisées selon les besoins du dispositif et la stabilité requise.
Le choix du baud rate dépend des exigences de l’application, de la capacité des périphériques et de la qualité de la connexion.

2. Data Bits (Bits de Données)
Les bits de données spécifient le nombre de bits transmis pour chaque unité de données. Les valeurs courantes sont 5, 6, 7, ou 8 bits. Par exemple, 8 bits de données permettent de représenter un octet (0-255), ce qui est courant dans de nombreuses applications.

3. Stop Bits
Les stop bits sont utilisés pour indiquer la fin d'un caractère de données. Ils aident à synchroniser l'émetteur et le récepteur en fournissant un intervalle de repos avant le début de la transmission suivante. Les options les plus courantes sont :

1 stop bit : Utilisé dans la plupart des communications série.
1,5 stop bits : Moins courant, parfois utilisé avec 5 bits de données.
2 stop bits : Utilisé lorsque des erreurs de synchronisation peuvent survenir, ou pour des transmissions plus lentes.
Les stop bits ajoutent un délai entre les caractères et peuvent réduire le débit global de transmission.

4. Parité
La parité est une méthode de détection d'erreurs qui ajoute un bit supplémentaire pour vérifier l'intégrité des données transmises. Ce bit peut être configuré comme suit :

Parité paire (Even) : Le bit de parité est réglé pour que le nombre total de 1 dans le mot de données soit pair.
Parité impaire (Odd) : Le bit de parité est réglé pour que le nombre total de 1 dans le mot de données soit impair.
Parité marquée (Mark) : Le bit de parité est toujours à 1.
Parité espacée (Space) : Le bit de parité est toujours à 0.
Aucune parité (None) : Aucun bit de parité n'est ajouté (courant dans de nombreuses applications).
Le contrôle de parité permet de détecter certaines erreurs simples mais n'offre pas une protection complète contre les erreurs.

5. Flow Control (Contrôle de Flux)
Le contrôle de flux régule le flux de données entre l’émetteur et le récepteur pour éviter la perte de données si un dispositif est plus rapide que l’autre. Les types de contrôle de flux les plus courants sont :

Aucun (None) : Pas de contrôle de flux. Les dispositifs doivent gérer eux-mêmes la gestion des données.
Matériel (Hardware, RTS/CTS) : Utilise les signaux RTS (Request to Send) et CTS (Clear to Send) pour coordonner le flux de données.
Logiciel (XON/XOFF) : Utilise des caractères spéciaux (XON et XOFF) pour indiquer quand commencer et arrêter la transmission des données.
Exemple de Configuration Série
Une configuration typique pourrait ressembler à ceci :

Baud Rate : 9600
Data Bits : 8
Stop Bits : 1
Parité : Aucune
Flow Control : Aucun
Représentation des paramètres série
En général, les paramètres sont souvent représentés de manière abrégée dans le format suivant :

plaintext
Copier le code
9600,8,N,1
Où :

9600 représente le baud rate.
8 représente le nombre de bits de données.
N signifie aucune parité.
1 indique un stop bit.
Récapitulatif des principaux paramètres et options
Paramètre	Options courantes	Description
Baud Rate	9600, 19200, 115200 bps, etc.	Vitesse de transmission
Data Bits	5, 6, 7, 8	Nombre de bits pour chaque unité de données
Stop Bits	1, 1,5, 2	Bits de fin pour chaque unité de données
Parité	None, Even, Odd, Mark, Space	Bit de contrôle d'intégrité
Flow Control	None, RTS/CTS (hardware), XON/XOFF (software)	Méthode de régulation du flux de données
Conclusion
La configuration des paramètres série est cruciale pour assurer une communication fiable et sans erreur entre deux dispositifs. Un désaccord sur l'un de ces paramètres entre l'émetteur et le récepteur peut entraîner des données corrompues ou une absence de communication.
