Pour permettre à vos routeurs de s’adapter automatiquement aux changements de topologie, l’utilisation de protocoles de routage dynamiques est essentielle. Ces protocoles permettent aux routeurs d’échanger des informations sur les réseaux disponibles et de recalculer les chemins optimaux en cas de modification de la topologie (comme l’ajout ou la suppression de liens). Parmi les protocoles de routage dynamiques les plus couramment utilisés, on trouve OSPF (Open Shortest Path First) et EIGRP (Enhanced Interior Gateway Routing Protocol).

Dans ce guide, nous allons nous concentrer sur la configuration d’OSPF, car il est largement utilisé et compatible avec divers équipements réseau. Nous verrons également brièvement comment configurer EIGRP en alternative.

1. Comprendre les Protocoles de Routage Dynamiques
OSPF (Open Shortest Path First)
Type de protocole : Routage à état de liens (Link-State)
Hiérarchie : Divisé en zones pour une meilleure scalabilité
Avantages :
Convergence rapide
Adaptabilité aux changements de topologie
Supporte la hiérarchie des zones
EIGRP (Enhanced Interior Gateway Routing Protocol)
Type de protocole : Routage hybride (propriétaire Cisco)
Avantages :
Convergence rapide
Facilité de configuration
Utilisation efficace de la bande passante
2. Configuration d’OSPF dans Cisco Packet Tracer
2.1. Création de la Topologie Réseau
Ouvrez Cisco Packet Tracer et ajoutez au moins deux routeurs et des switchs interconnectés.
Connectez les routeurs entre eux et aux différents segments de réseau à l’aide de câbles appropriés (généralement des câbles série ou Ethernet).
Configurez les adresses IP sur les interfaces de chaque routeur pour assurer la connectivité de base.
2.2. Configuration de Base des Routeurs
Supposons que nous avons deux routeurs, R1 et R2, connectés directement via une interface série.

Configuration de R1
bash
Copier le code
R1> enable
R1# configure terminal
R1(config)# hostname R1

# Configuration de l'interface série
R1(config)# interface serial0/0/0
R1(config-if)# ip address 192.168.12.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# exit

# Configuration des autres interfaces si nécessaire
# Exemple pour une interface Ethernet
R1(config)# interface gigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
Configuration de R2
bash
Copier le code
R2> enable
R2# configure terminal
R2(config)# hostname R2

# Configuration de l'interface série
R2(config)# interface serial0/0/0
R2(config-if)# ip address 192.168.12.2 255.255.255.252
R2(config-if)# no shutdown
R2(config-if)# exit

# Configuration des autres interfaces si nécessaire
# Exemple pour une interface Ethernet
R2(config)# interface gigabitEthernet0/0
R2(config-if)# ip address 192.168.2.1 255.255.255.0
R2(config-if)# no shutdown
R2(config-if)# exit
2.3. Configuration d’OSPF
Sur R1
bash
Copier le code
R1(config)# router ospf 1
R1(config-router)# network 192.168.12.0 0.0.0.3 area 0
R1(config-router)# network 192.168.1.0 0.0.0.255 area 0
R1(config-router)# exit
Sur R2
bash
Copier le code
R2(config)# router ospf 1
R2(config-router)# network 192.168.12.0 0.0.0.3 area 0
R2(config-router)# network 192.168.2.0 0.0.0.255 area 0
R2(config-router)# exit
2.4. Vérification de la Configuration
Vérifiez les voisins OSPF pour s’assurer que les routeurs ont établi une relation adjacente.

bash
Copier le code
R1# show ip ospf neighbor
Vérifiez la table de routage pour voir les routes apprises via OSPF.

bash
Copier le code
R1# show ip route ospf
Testez la connectivité en utilisant la commande ping entre les réseaux connectés aux deux routeurs.

bash
Copier le code
R1# ping 192.168.2.1
2.5. Gestion des Changements de Topologie
Pour observer la capacité d’OSPF à s’adapter aux changements, procédez comme suit :

Désactivez une interface sur R2 pour simuler une panne.

bash
Copier le code
R2(config)# interface serial0/0/0
R2(config-if)# shutdown
Vérifiez la table de routage sur R1 pour voir comment OSPF a recalculé les routes.

bash
Copier le code
R1# show ip route ospf
Réactivez l’interface sur R2.

bash
Copier le code
R2(config-if)# no shutdown
Vérifiez à nouveau la table de routage sur R1 pour voir la récupération de la route.

bash
Copier le code
R1# show ip route ospf

4. Configuration d’OSPF avec Plusieurs Zones
Pour des réseaux plus complexes, il est recommandé d’utiliser des zones OSPF pour optimiser le routage.

4.1. Exemple de Configuration avec Deux Zones
Supposons que vous avez trois routeurs : R1, R2, et R3.

R1 et R2 sont dans la zone 0 (Backbone).
R3 est dans la zone 1.
Configuration sur R1
bash
Copier le code
R1(config)# router ospf 1
R1(config-router)# network 192.168.12.0 0.0.0.3 area 0
R1(config-router)# network 192.168.1.0 0.0.0.255 area 0
R1(config-router)# exit
Configuration sur R2
bash
Copier le code
R2(config)# router ospf 1
R2(config-router)# network 192.168.12.0 0.0.0.3 area 0
R2(config-router)# network 192.168.2.0 0.0.0.255 area 0
R2(config-router)# network 192.168.23.0 0.0.0.3 area 1
R2(config-router)# exit
Configuration sur R3
bash
Copier le code
R3(config)# router ospf 1
R3(config-router)# network 192.168.23.0 0.0.0.3 area 1
R3(config-router)# network 192.168.3.0 0.0.0.255 area 1
R3(config-router)# exit
4.2. Vérification
Vérifiez les voisins OSPF sur chaque routeur.

bash
Copier le code
R1# show ip ospf neighbor
R2# show ip ospf neighbor
R3# show ip ospf neighbor
Vérifiez les routes apprises dans la table de routage.

bash
Copier le code
R1# show ip route ospf
R2# show ip route ospf
R3# show ip route ospf
5. Avantages des Protocoles de Routage Dynamiques
Adaptabilité : Les routeurs ajustent automatiquement les chemins en cas de changement de la topologie.
Efficacité : Optimisation des routes en fonction des métriques définies (coût, bande passante, délai, etc.).
Scalabilité : Facilité d’extension du réseau sans reconfiguration manuelle complexe.
Résilience : Amélioration de la disponibilité grâce à la redondance et à la détection rapide des pannes.
6. Meilleures Pratiques
Planification des Adresses IP : Assurez-vous que les sous-réseaux sont bien planifiés pour éviter les chevauchements.
Hiérarchisation des Zones (pour OSPF) : Utilisez des zones OSPF pour segmenter le réseau et réduire la charge sur les routeurs backbone.
Sécurité des Protocoles de Routage : Implémentez des mécanismes d’authentification pour sécuriser les échanges de mises à jour de routage.
Surveillance et Maintenance : Utilisez des outils de surveillance pour suivre les performances du routage dynamique et détecter les anomalies.
7. Conclusion
L’utilisation de protocoles de routage dynamiques comme OSPF et EIGRP permet de créer des réseaux robustes et adaptatifs, capables de s’ajuster automatiquement aux changements de la topologie. En configurant correctement ces protocoles dans Cisco Packet Tracer, vous pouvez simuler des environnements réseau complexes et préparer vos configurations pour des déploiements réels.

N’hésitez pas à pratiquer ces configurations dans Cisco Packet Tracer en créant différentes topologies et en testant la réaction des protocoles de routage aux modifications de la structure réseau. Cela renforcera votre compréhension et votre maîtrise des protocoles de routage dynamiques.
